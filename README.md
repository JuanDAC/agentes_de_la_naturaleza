

<h1 align="center">🌻 Nature Agents 🌍</h1>

## Description 🎮

"Nature Agents" is an innovative video game that offers solutions to various environmental problems in the San Cristóbal neighborhood, located in the southeast of Bogotá DC. The project is unique in that it incorporates drawings created by local children, which were digitized and transformed into an engaging and educational gaming experience. 🖍️➡️🕹️
